3D renderer written in rust. Uses openGL 4.6. With this project i covered almost all LearnOpenGL lessons. It is unfinished because the code got messy and i got bored of it. 
Features are SSAO (based on scene depth + scene normals), Shadow mapping and some post processing effects.
